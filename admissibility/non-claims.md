# Non-Claims

This repository is intentionally narrow. It is an interoperability exploration, not an endorsement claim or replacement architecture.

## This project does not claim

- endorsement by the authors of any ARA paper
- endorsement by any ARA implementation, site, lab, or research group
- certification of ARA artifacts
- validation of any external research artifact
- replacement of the ARA architecture
- superiority over ARA or any other research-artifact format
- compatibility accepted by any upstream ARA project
- authority to define ARA itself
- authority to define publication acceptance rules for any journal, conference, lab, platform, or repository

## This project does claim

- ARA-style artifacts and admissibility evaluation can be treated as different layers.
- Reconstructability and standing are not identical.
- An artifact can be reproducible without automatically being admissible for a specific downstream use.
- A commitment candidate can provide a narrow bridge between artifact reconstruction and commit-time standing evaluation.

## Preferred framing

Use this framing when discussing the project publicly:

> This repository explores whether agent-native research artifacts can be evaluated as commitment candidates under a commit-time admissibility model. It does not replace ARA; it tests the standing layer that may be needed before artifacts are accepted, cited, executed, published, or relied upon downstream.

## Collaboration posture

This repository should remain open to correction, terminology alignment, and boundary refinement. External terminology should be cited, dated, and distinguished from StegVerse-specific usage when added.
